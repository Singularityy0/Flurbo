Settlement

ItemStatusDetailNext step
Missing data is never Noby designAn outage, rate limit, layout change or unpublished release leaves the question unanswered; a person asserts or it goes VOID.Write rules so No is a positive reading (count 0 from a complete list).
Legacy release rule proves only YesopenRelease milestones: reth v2.6.1 needs a manual No by 8 Oct 00:01 UTC. Older audit item N3 is fixed for the general readers.Use counting rules for future release questions.
Bot does not finalize other wallets' assertionsopennextResolutionAction finalizes only its own assertions and timeouts. A manual assertion needs a manual finalize.Let the bot finalize any unchallenged assertion after its challenge period.
Bond credits are never withdrawn by the botopenPilotResolver.finish credits bonds; collecting needs withdrawBond() from the signer, whose key exists only on Render. About 1 test AUSD stays in each resolver per bot assertion.Add a withdrawBond action to the worker after delivery.
Answers wait for the capture window to closeby designThe resolver accepts assertions only after the observation end (audit item N2). Payout comes at window close plus the challenge period.Keep windows short where sources are reliable.
Shared IP rate limitsopenBLS API v1 (about 25 requests a day per IP; exhausted locally on 1 October by rule checks) and GitHub (60 an hour) are shared with other tenants of Render's addresses.Short windows, manual fallback; consider a registered BLS key only if its evidence can stay public.
Monad public RPC prunes stateby designContract state older than a few days cannot be read, so price and supply readings must be captured within hours.
TSE layout not verifiable before election nightopenBrazil rules read candidate rows by ballot number and fail closed if fields are missing, but a changed status string (for example 2° turno) would read as No.Compare the live file on 5 October 01:00 to 05:30 UTC; hold the pool if anything differs.
Page reader is brittleby designhtml-text.v1 breaks on layout changes (EIA).Prefer data sources.
Rule check cannot tell a quota refusal from a rule problemopenBLS quota refusals show as OBSERVATION_IDENTITY_MISMATCH; F1 was prepared with a temporary allowance.Recognize known refusal messages, or rerun from another IP.
Captures stored in Redisby design2 MB cap per response; large responses cost Upstash bandwidth and commands on the free plan.Keep responses under 500 KB.
One signer, one pending transactionby designUp to 12 transactions per cycle; a burst of 16 assertions takes 2 to 3 cycles.
Operator-controlled reviewers, 1 AUSD bondsby designNo economic security; disputes are decided by wallets the operator controls. Disclosed in every pool.Independent panel, or integration with Kleros, Reality.eth or Seer (not started).
Settlement rule schema too thin for official statisticsfixedflurbo.settlement-rule.v1 has vintage, publication cutoff, correction cutoff and reader settings.
